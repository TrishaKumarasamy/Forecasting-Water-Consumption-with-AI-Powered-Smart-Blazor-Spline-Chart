# Water Consumption Forecasting with AI-Powered Blazor Spline Chart

An intelligent water consumption forecasting application built with **Blazor Server**, **[Blazor Charts]()**, and **Azure OpenAI**, demonstrating real-time data visualization and AI-powered predictions.

## Overview

This application showcases how to build a modern data analysis platform that combines interactive charts with AI-powered forecasting. Using historical water consumption data from New York City, the application leverages Azure OpenAI to generate realistic 5-year forecasts, visualized in real-time on an interactive spline chart.

The project demonstrates best practices for:
- Building responsive Blazor Server applications with real-time data updates
- Integrating components for advanced data visualization
- Connecting to Azure OpenAI for intelligent data analysis
- Implementing smooth UI animations and loading states

## Features

- **Interactive Spline Chart** - Visualize historical and forecasted water consumption with zoom and tooltip capabilities
- **AI-Powered Forecasting** - Generate intelligent predictions using Azure OpenAI based on historical trends
- **Real-Time Data Updates** - Animate forecast data points as they're generated
- **Responsive Design** - Built with Bootstrap 5 for modern, mobile-friendly UI
- **Visual Indicators** - Striplines highlight forecasted vs. historical data regions
- **Loading States** - Smooth spinner and button animations during data generation

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/Forecasting-Water-Consumption-with-AI-Powered-Smart-Blazor-Spline-Chart.git
cd Forecasting-Water-Consumption-with-AI-Powered-Smart-Blazor-Spline-Chart
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
